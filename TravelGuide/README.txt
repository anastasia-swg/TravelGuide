ВАРИАНТ ЗАДАНИЯ: Spring №2

Необходимо реализовать REST API путеводителя по городу.
В БД сервиса хранятся достопримечательности городов с указанными названием, категорией и географическими координатами. Также для каждой достопримечательности пользователи могут написать свой отзыв, а также выставить свою оценку от 1 до 5.
У пользователя должна быть возможность:
1.	Получить список достопримечательностей, находящихся в указанном радиусе от него (координаты пользователя передаются в запросе) с возможностью их фильтрации по категории и (или) средней оценке. Максимальное количество предлагаемых достопримечательностей и параметр, по которым они должны быть отсортированы также может быть указан (по умолчанию — 10 достопримечательностей, отсортированных по близости к пользователю).
2.	Выставить оценку достопримечательности
3.	Написать отзыв о посещении
достопримечательности
4.	Посмотреть информацию и среднюю оценку
по конкретной достопримечательности
5.	Посмотреть отзывы о конкретной
достопримечательности
Важно:
Сервис должен быть написан на Spring или Spring Boot, код должен содержать unit-тесты, сервис должен собираться при помощи Maven или Gradle, код сервиса должен содержать скрипты развертывания БД (в идеале — скрипты Liquibase или Flyway).

ОПИСАНИЕ ПРОЕКТА:

REST API сервис для поиска достопримечательностей с фильтрацией по категории, 
оценкам и географическому радиусу. Пользователи могут оставлять отзывы и ставить оценки.

Возможности->
-Сортировка и фильтрация достопримечательностей:
  - По рейтингу и расстоянию
  - Фильтр по категории (Музей, Парк, Памятник, и т.д.)
-Система отзывов:
  - Автоматическое создание пользователя при первом отзыве
  - Оценка от 1 до 5
-Автоматический пересчёт среднего рейтинга через триггеры БД
-Определение геолокации через браузер
-Flyway для управления миграциями БД
-Unit-тесты (JUnit 5 + Mockito)

Технологии->
- Java 17
- Spring Boot 4
- PostgreSQL
- Flyway
- Maven

ПОДГОТОВИТЕЛЬНЫЕ ДЕЙСТВИЯ И ЗАПУСК ПРОЕКТА:

(Запуск проекта осуществляется после проверки наличия/наличия требуемых технологий)

Запуск:
 1. Скачать и распаковать zip архив с github;
 2. В корневой папке проекта (TravelGuide) открыть терминал и выполнить команды:
    - Windows: mvnw spring-boot:run
    - Linux: ./mvnw spring-boot:run
 3. Дождаться сообщения в терминале: "Started TravelGuideApplication in (..) seconds" и "FLYWAY INFO! wait migrations: 0"
 4. Открыть в браузере: http://localhost:8080

ИСПОЛЬЗОВАНИЕ И РЕАЛИЗАЦИЯ ПРОЕКТА:

Поиск достопримечательности выполняется по ее индивидуальному номеру.

В рамках учебной задачи отсутствует регистрация пользователя и привязка email и пароля, отсутствует реализация аккаунта администратора и следовательно отсутствует возможность обновления списка достопримечательностей вне CУБД.
